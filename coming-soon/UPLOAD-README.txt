TEM BAKEHOUSE | COMING SOON

UPLOAD TO CPANEL
1. Back up the current files in your domain's document root.
2. Upload coming-soon-cpanel.zip with cPanel File Manager.
3. Extract it directly inside the domain's document root (usually public_html).
4. index.html, styles.css, script.js and assets/ must sit directly in that root.
5. If an older index.php exists, rename it after backing it up so it does not
   take priority over this index.html. Keep any unrelated site files intact.
6. Visit your domain and hard-refresh the browser to check the result.

No installation, compilation, database, PHP or external service is required.
All images are included. The page works in a subfolder, too.

CUSTOMISING
- Edit copy and page metadata in index.html.
- Edit the colour variables at the top of styles.css.
- The page follows the visitor's light/dark colour preference.
- The responsive layout fits one viewport, with compact phone/landscape layouts.
- Motion respects the visitor's reduced-motion preferences.
- The cookie preview includes three flavours and a virtual bite interaction.
- No personal information is collected. There is no signup form or backend.
- No launch date or contact details have been invented.

Existing TEM logo and cookie images were reused from the parent project.
